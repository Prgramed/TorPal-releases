# TorPal releases

Signed and notarized builds of TorPal, a native macOS torrent client, plus the Sparkle update feed.

- Downloads: see [Releases](https://github.com/Prgramed/TorPal-releases/releases).
- Update feed: `https://prgramed.github.io/TorPal-releases/appcast.xml` (used by the app; you don't need to open it).

Source code is developed in a private repository. Builds here are published by `scripts/publish-release.sh`.
